The file `changes.md` in your working directory lists each change id. First, write one line per change, exactly one of these three forms, using those ids:

VERDICT <id>: adopt
VERDICT <id>: adopt with changes
VERDICT <id>: reject

`reject` is a valid answer. The existing rules may already cover the problem, or the change may make things worse.

Then, for each change: which existing rules already address the problem and why they did not prevent it; the defects; and draft wording when the verdict is `adopt with changes`. The motivating feedback is input to weigh, not the answer key.
